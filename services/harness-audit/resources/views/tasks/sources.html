How delegation works

Agent runs

Open an item and delegate it to a repository. The agent gets the item as fenced, size-capped text with no access to the task manager, plans, builds on its own branch, is verified and independently reviewed, and opens a draft pull request. You approve the plan and the review here. Nothing merges on its own.
